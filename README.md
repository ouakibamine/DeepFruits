# DeepFruits
# Projet Fin d'Etude - DEEPFRUITS

![DeepFruits Logo](created-the-model/image.png)

## A propos

DeepFruits offre la possibilité d'identifier le type et l'état des fruits, en s'appuyant sur les réseaux de neurones convolutifs.

DeepFruits est développé par OUAKIB Amine et RAMADI Hamza, sous la direction de Mme ZAHIR Jihad à la faculté des sciences semlalia Marrakech, Département d'informatique.

## Démonstration

La fonctionnalité de notre application web est de faciliter à l'utilisateur l'évaluation de notre système que nous avons développé. Dans cette partie, l'utilisateur trouvera deux boutons. Le premier permet d'importer une image et le deuxième affiche un tag décrivant la prédiction du fruit présenté par l'image.

![Application Interface](created-the-model/interface.png)

## Contribution

Le manque de dataset est l'un des problèmes rencontrés lors du développement de ce projet. L'utilisateur peut contribuer en fournissant des images en cliquant sur le bouton "Ajouter" qui s'affiche lorsque l'image est prédite avec au moins 90% d'exactitude. Ces images seront consultées périodiquement par l'équipe du projet qui sélectionnera les bonnes images pour enrichir le dataset et ré-entraîner le modèle avec ce nouveau dataset.

![Ajouter](created-the-model/ajouter.png)
